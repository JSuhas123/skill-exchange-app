## Troubleshooting

### If app still crashes after cache clear and installation:

**1. Check Android version**
- Minimum required: Android 7.0 (API 24)
- Optimal: Android 9.0+ (API 28+)

**2. Check storage space**
- Free up at least 100 MB of storage
- Settings → Storage → Clean up unused files

**3. Collect error logs**
```bash
adb logcat > error_logs.txt
# Reproduce the crash
# Attach error_logs.txt to bug report
```

**4. Force complete removal**
```bash
adb shell pm clear com.example.skillexchange
adb uninstall com.example.skillexchange
adb install -r skill-exchange-app-v2.0-fixed.apk
```
